# SEDS Lab 3: Object-Oriented Programming and Python Packaging

This repository contains the completed assignments and refactored code for SEDS Lab 3. The project demonstrates core software engineering principles in Python, transitioning from foundational script writing in Jupyter Notebooks to robust, structured software packages.

**Core Objectives**

* **Object-Oriented Design:** Implementation of base and derived classes, specifically modeling `Rocket` and `Shuttle` entities to demonstrate inheritance, instance attributes, and method overriding.
* **Code Refactoring:** Extraction of mathematical sequence calculations from procedural scripts into modular, reusable Python functions.
* **Standardized Packaging:** Utilization of the Cookiecutter utility to scaffold a professional Python project directory, establishing standard locations for source code, tests, and configuration files.

**Prerequisites**

* Python 3.8 or higher
* Cookiecutter (`pip install cookiecutter`)
* Jupyter environment (to run the original lab `.ipynb` file)

**Project Architecture**

* `notebooks/`: Contains the iterative Jupyter Notebook detailing the progression from OOP basics to module creation.
* `src/`: The main source directory containing the extracted Python modules for the rocket models and mathematical sequences.
* `tests/`: Directory reserved for unit testing the logic separated during the module refactoring phase.
* `setup.py` / `pyproject.toml`: Dependency and metadata configuration generated by Cookiecutter for local package installation.

**Installation and Usage**

To utilize the refactored code outside of the Jupyter environment, install the package locally in editable mode. Navigate to the root directory containing the setup configuration and execute the following command:

```bash
pip install -e .
```

After installation, the modules can be imported and executed in any local Python environment or script.

```python
from seds_lab.models import Rocket, Shuttle
from seds_lab.sequences import calculate_sequence

# Instantiate an object from the refactored OOP module
discovery = Shuttle()
```
